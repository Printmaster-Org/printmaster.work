A few quick answers

Before you
get started.

Visit the documentation ↗
Do I need to install a Server?

No. An Agent can run standalone and provide its local web interface. The central Server is optional and intended for aggregating multiple site Agents.

Will PrintMaster find every printer?

Discovery depends on network reachability, SNMP configuration, and device support. Keep SNMP enabled and allow the Agent to reach the printer network; available data varies by model and firmware.

Where do I get the Windows installer?

Open GitHub Releases, choose the latest Agent release, and download its Windows x64 MSI. Release assets are versioned, so the Releases page is the stable download link.

Where are installation and configuration guides?

Visit the PrintMaster documentation site for step-by-step setup, configuration, deployment, and troubleshooting guides.
